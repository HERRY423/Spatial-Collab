# 大数据与多样本统计验收（版本号保持不变）

产品版本仍为 **0.7.0a1 / 0.7.0-alpha.1**。以下是本机工程与数值证据，不是独立科研评测或用户效率试验。时间为单次实际运行，包含本机文件缓存、同时运行任务等影响，不是跨设备性能保证。

## 百万对象与分子

开发者明确生成的规模控制包含：1,000,000 对象、30,001 特征、2,000,000 稀疏计数记录、2,000,000 转录本、2,000 个细胞/核多边形。测试采用磁盘流式索引，未将全部计数转换成对象 JSON。合成图层用于检查各自 I/O、身份与位置，不代表一致的实验测量或生物学组织。

| 检查 | 实际结果 |
|---|---|
| 索引构建 | 142.76 秒；数据库 595,197,952 bytes |
| 百万对象全景 | 20.01 ms，密度格计数总和恰为 1,000,000 |
| 两百万分子全景 | 27.76 ms，密度格计数总和恰为 2,000,000 |
| 精确局部对象查询 | 31.89 ms |
| 分子特征索引查询 | 41.98 ms |
| 局部边界查询 | 7.44 ms |
| 冻结 1,024 × 30,001 稀疏 ROI | 1.23 秒，原始计数与完整特征轴保留 |
| 该进程峰值工作集 | 268,550,144 bytes，约 256 MiB；包括测试图像生成与查询 |

记录：`output/scalability/million-optimized.json`。较早、正确但未优化的结果也保留在 `million-scale.json`：分子全景约 3.94 秒，指定特征查询约 2.44 秒。通过分子密度金字塔、全景已知计数及优先使用特征索引降低读取时间，并非减少返回统计范围。

## 真正的十亿像素原生金字塔

通过逐瓦片生成 **32,768 × 32,768（1,073,741,824 像素）、8 层 tiled OME-BigTIFF**。没有创建整幅图像数组。文件使用易压缩合成纹理，编码大小约 16 MB；不是实际染色组织的压缩率测试。

每层读取右下角瓦片，与已知全分辨率生成公式逐像素比较，8 层均一致。覆盖最高分辨率层、降采样层、远端偏移和像素中心仿射映射。独立读取进程峰值工作集约 **74.4 MiB**，见 `output/scalability/gigapixel-read.json`。含 TIFF 生成的另一个进程峰值约 675 MiB，完整记录见 `gigapixel-validation.json`；不把生成阶段占用隐去或混同为读取占用。

网页实际显示该 8 层图像，并从全景缩放到 3,081 个精确分子，随后平移查询；分子与细胞/核边界开关、同坐标图像、比例保持及浏览器错误检查均纳入验收。截图在 `output/scalability/browser-*.png`。

## 公开数据保持完整

从此前已核实的公开 SPOTS spleen-1 冻结输入读取 300 spots、32,285 基因、**1,052,344 个非零计数**，转换为磁盘索引后重新冻结整个 ROI。稳定 ID 显式限定样本、坐标逐值相同、按基因 ID 重排后的稀疏差矩阵 **nnz = 0**；导入约 15.77 秒。该样本没有提供本次所需的真实分子/组织图像，未据此声称验证了实际 Xenium/CosMx 全目录。

记录：`output/scalability/public-validation.json`，包含原输入 ID 与哈希。未用合成表达填补公开数据。

## 多样本统计与复算

已知生成模型检查包括独立受试者、同人配对、重复切片、批次固定效应和受试者随机截距。Welch 与直接计算的 Welch–Satterthwaite 公式一致；配对检验使用同一 subject_id；24 位合成受试者、144 个切片值的 LMM 得到约 1.469 的条件效应（生成效应 1.5），并通过预先设定的数值容差检查。此例不能估计一般化的假阳性率或覆盖率。

检查还覆盖源/run 不匹配、缺失指标、整位受试者缺失处理、完整混杂、计数尺度拒绝、固定效应秩与拟合诊断。Welch、paired_t、mixedlm 的三份结果都从审阅包独立复算一致。见 `output/scalability/study-validation.json`。

真实 MCP stdio 客户端已执行：大型数据集发现、百万对象全景、分子特征查询、图像瓦片、4 × 30,001 ROI 冻结、研究设计登记、LMM 执行和结果读取。见 `output/scalability/protocol-validation.json`。这不是 ChatGPT/Claude Code 真实用户接受度验证。

## 修复过程与交付边界

- 首轮全景范围只覆盖质心，导致边缘分子少计：现按质心、转录本与边界联合范围构建；增加总计数回归。
- 原生 TIFF 的第 0 层接口返回多尺度组而非数组：改用显式 series/level 读取；增加最高分辨率远端瓦片逐像素检查。
- 图像与点层统一保留长宽比、按实际视口裁切；图层状态通过共享上下文明确记录 atlas、坐标系、视野、特征与图像，独立于原有注释选区。
- 旧 JSON 导入路径和具体科学算法的有界预算保留。已验证的是新增磁盘路径与局部分析，不是所有算法百万对象整图训练。
- 源 TIFF、atlas 数据库为外部大资源；原审阅包只含资源清单、冻结 ROI 计数与统计记录，验证器明确区分清单校验和像素/数据库迁移。
- 未实现云 OME-Zarr/DZI、分割编辑、通用任意 LMM 结构或小样本自由度校正。现场校准、真实跨患者设计及独立用户收益仍待验证。

最终完整回归为 **493 passed / 3 skipped**（54.11 秒），包括空容器初始化、实际 atlas 导入与 ROI 导出复算、共享视野和不可变主选区检查。跳过项为未安装 SpatialData 和两项原生 napari 检查。安装包使用相同版本重新构建并安装到独立目录，真实 MCP 调用覆盖共享视野往返及上述科学操作。完整测试、安装包一致性、浏览器和发行哈希记录在 `output/scalability/delivery-verification.json`。
