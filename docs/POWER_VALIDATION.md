输入沿用此前冻结的 `analysisinput_1d1dabc1a7b372919b635fd033b6592a`，300 spots、32,285 测量特征。本数据此前已经分析，因此此次所有功效计划都如实标为 **retrospective_sensitivity**。

另外执行了**模型条件演示场景**：假定 BH 排序恰为上表最低可达位置，使用这份公开数据的真实空间图、200 次独立模拟、固定种子 731、rho 网格 `[0,.2,.4,.6,.8,.95]`、目标功效 80%。这是稠密信号排序的规划假设，**没有证据表明真实数据存在这么多信号**。

| 条件模拟输出 | Gaussian SAR / Moran | Lognormal neighbor coupling / LR |
|---|---:|---:|
| 网格 MDE rho | 0.4 | 0.4 |
| 该点生成效应中位数 | Moran I = 0.1563 | 相对随机摆放期望超额 = 0.2642 |

Moran I=0.1563 是生成分布的中位数，**不是对任意实测基因套用的检测阈值**。LR 模型尚未校准真实 log-normalized RNA、零值或复合体测量误差，不能称为生物学通讯检测功效。模型、全部曲线、输入/输出哈希、旧与新结果 ID 保存在 `output/power/public-power-validation.json`；复现入口为 `scripts/validate_power_public.py`。

## 回归与产品验收

覆盖：BH 精确整数边界、稀疏不可能与稠密可拒绝反例；Moran 模拟与独立密集矩阵公式逐值对照；两种模型的零效应/强效应与可重复性；目标家族与归一化过滤；修改预算拒绝旧计划；声明先于模拟及目标运行；已有结果保持回顾性标签；离线功效与分析复算；11 方法责任分层；篡改环境/输出收据拒绝。

完整回归、安装包内容核对、实际 MCP 和浏览器证据见 `output/power/delivery-verification.json`。原有规模测试和 v0.7 方法运行记录保持为历史证据，本次未把适配器工程测试升级成上游算法的科学验证。

最终完整回归：**509 passed / 3 skipped，77.78 秒**；跳过为 SpatialData 未安装及两项原生 napari 检查。16 项新增用例包括已提交/排队分析不得再称为先验的时序边界，以及独立边权求和复算 LR 分数、置换 p 值和 FDR。

真实 MCP 验收由 `scripts/check_power_protocol.py` 创建独立的合成工作区，经过配置环境子进程创建计划、读取声明、后台执行、结果分页回读，验证数值层与冻结计划关联；不把该工作区描述为独立研究者试用。
