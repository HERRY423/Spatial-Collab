## 真实公开数据

三份数据共 7,827 个空间观测对象，不等同于 7,827 个生物学重复。拟合默认只选择记录下来的 128 个 RNA 特征，完整原始 RNA 面板仍保留；不存在把所选特征数量当成导入面板大小的问题。

扁桃体文件从官方 SMOPCA 固定提交获取，SHA256 为 `67ee4f78382c53580be49a2ba65e74a3c350834cf7ee08cc3a29e6bd8b11a336`。逐值核对全部原始 ID、XY、RNA、ADT 通过。RNA 项目面板按 ID 排序，核对通过原始基因 ID 重新排列，未将排序后的面板与原始列位置硬配对。未将归一化矩阵充当原始计数，未猜测坐标物理单位，未虚构人工细胞类型修订。

初次基线执行耗时约为 151.87 / 33.71 / 36.04 秒；SMOPCA 在扁桃体、spleen 1 分别约 158.71 / 41.72 秒。时间包含读取、校验与对照，来自单机执行，不能作为广泛性能基准。结果 ID、源摘要、特征轴、方法设置、版本和分歧对象分别保存在 `output/v06/validation-balanced_pca.json` 与 `validation-smopca.json`。

## 发现并处理的问题

1. 首次 SMOPCA 运行因模态平衡后的尺度不符合官方模型的单位方差输入而求根失败。修正适配预处理，官方模型未改动，不用 PCA 结果冒充 SMOPCA。
2. Windows 独立环境的 MCP 首次在后台线程导入 SciPy 原生扩展时卡住。科学模块改为服务主线程预加载后，真实协议响应和退出均通过。
3. 默认 BLAS 多线程的 SMOPCA 离线复算出现不一致，保留 `public-integrity-cross-build.json`。固定单线程后，跨环境最大嵌入差异约 5.24e-13，簇完全一致；相同环境的两次拟合差异为 0。实现明确限制内置拟合和复算的 BLAS 线程，并记录库构建信息；没有放宽容差。

数值重复性原始记录在 `output/v06/smopca-repeatability.json`。失败记录与修复后结果并存，不把一次成功回写为“从未失败”。官方参考模型仍受 3,000 个位置的计算预算限制，不是论文全部结果的复现。

## 独立试用与边界

按用户要求准备公开数据试用包，入口为 [中文试用指南](V06_PILOT_GUIDE.md)，现成文件在 `output/v06/user-pilot`。六个计划席位覆盖三种工作流的全部六种顺序；记录表为空，实际参与者 **0 人**。ROI 与评分依据需要独立研究者在正式试验前冻结。汇总脚本对空表明确返回 `no_observations`，不会生成效率结论。

未完成且不能由本地测试替代的验证：独立研究者的科学正确性/时间收益评价、真实 ChatGPT 与 Claude Code 自然语言协作验收。当前跨样本能力是研究设计与个体层级描述汇总，不是跨患者联合模型或统计推断；非同对象对应关系目前只登记检查，不自动运行配对整合。蛋白校正对象记录声明与控制依据，不代表校正效果已经独立验证。
