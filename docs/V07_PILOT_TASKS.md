# v0.7 可执行分析试用任务补充

状态：任务材料已准备，未招募、未计时、未独立评分。继续使用 v0.6 试用包的三组条件、匿名记录表与顺序平衡；不得用开发者运行记录填入独立用户结果。

本补充供正式试用前由独立研究者选择、冻结任务和评分证据。各比较组须使用同一公开数据、相同算法版本、参数、计算资源及可用证据。不能把算法更换的效果归因于插件。

| 任务 | 研究者实际操作 | 交付及核对点 |
|---|---|---|
| RNA / 蛋白因子 | 在同一冻结 ROI 比较 MOFA 与 MEFISTO，查看两种模态的载荷及原始标记 | 明确哪个模型用了空间坐标；引用相同原始对象；不得直接命名因子为已验证细胞类型 |
| 参考去卷积 | 核对稳定基因 ID、原始参考标签；运行 NNLS 和 Cell2location | 区分 RNA 贡献和细胞丰度后验；记录先验依据、参考缺失类型、残差与区间；更换先验另建结果 |
| 批次与配准 | 对给定设计判断 Harmony 是否可运行；对已知变换控制运行 PASTE | 完全混杂必须保留失败；变换控制不冒充独立切片验证；原坐标保持不变 |
| 结构域 | 比较同一对象上的 SpaGCN 与空间谱聚类 | 只把分歧作为复核线索；回到原始 RNA / 蛋白证据；人工提案与计算标签分开 |
| SVG | 运行 Moran 置换检验，核对归一化、检验家族、最低 p 值及 BH | 不把原始计数方差排序或未校正 p 值当成 SVG 结论；保留低检出和常量状态 |
| 通讯 / 通路 | 检查一个数据库 LR 复合体的亚基覆盖，并查看 PROGENy 活性及覆盖 | 未测或重名亚基不作零信号；RNA 共表达、通路活性和因果传递分别陈述 |

对每项记录：冻结配方、输入哈希、任务 ID、所有成功/失败尝试、完成判据、独立评分依据、实际操作时间、等待时间、返工数、遗漏和错误、可复算结果路径。若任务无需正式注释修订，不应为展示闭环而制造修订。

与既有 notebook / 通用 Agent 比较时，同时考察正确率与耗时。尚不能声称本插件提高了独立研究者效率；公开数据运行只验证可执行性及明确的数值/对象契约。
