# 四项真实问题的修复与复测

2026-09-20 · Spatial Collab 0.4.0-alpha.1 · 本机工程和描述性分析验收。

这轮继续使用此前下载的原始数据。旧项目、失败记录和原文件保留；新分析位于 `projects/v04-real-data/`。没有把程序测试、标记规则、图像对应或方法间一致性当作生物学真值。

## 1. 让同一个对象关联图像和分割

新增本地资产登记，要求原项目来源散列、切片、样本（存在时）、坐标系、单位、明确的像素中心到空间坐标的二维仿射变换。分割标签对应细胞须提供原生 label→cell ID 映射，不能依照数组顺序猜测。图像、掩膜、变换与对应关系分别保存；每次检查/加载校验内容，napari 中的独立渲染副本不能反写登记源。

研究者可在 napari 叠加 Image、Labels 与同一项目的 Points；选中对象会对应共享选区。浏览器/Agent 的 `list_assets` 与 `inspect_asset` 返回最多 100 个指定对象的像素、标签和对应状态。移过的图层、错误来源/样本/框架、改过的内容被拒绝。支持有界二维 NPY 与显式 TIFF 页面；这是图像证据入口，还不是整张多分辨率切片系统，也不会编辑分割。

真实格式验收使用已有 Xenium kidney v4 tiny 的 358 个对象、DAPI TIFF 第 0 页和 `cells.zarr` 的 `masks/1` 无损 NPY 副本。坐标来自原生空间→像素变换的显式求逆，标签对应来自 `cell_boundaries.csv.gz` 的 `label_id`/`cell_id`，不假设第 n 个标签就是第 n 个细胞。隐藏原生 napari 实际加载了图像、掩膜与质心，并拒绝移动后的掩膜。

357 个质心落在其声明细胞的标签内，1 个落在另一声明细胞的标签内：`mnlmjgpm-1` 对应像素标签 221，而标签 221 声明对应 `ipcgjdge-1`。该差异保留供研究者检查，**不是分割准确率、自动分割合并结论或真实共表达判断**。本轮主分析的淋巴结没有同源图像/掩膜，仍明确返回缺少证据；不能用肾脏图替它作证。

本机记录：`projects/assets-native-acceptance-20260920/native-assets-receipt.json`；复现入口 `scripts/acceptance_assets.py`。实际使用说明见 [NAPARI.md](NAPARI.md)。

## 2. 未知标尺仍能完成表达与区域探索

坐标能力拆分为两层：`micrometer`、`pixel`、`array_index`、`unknown` 均可保存原坐标、选区、复核表达、提出注释修订及比较区域；物理半径图只接受 `micrometer`。单位随来源、选区、重放包与界面显示，不补造 spot 间距或像素大小。新假设计划可以记录未知单位的数据，但其物理分析格保持 unknown，而不是假装执行成功。

| HER2ST A1 | 346 spots × 12,562 genes；796,925 非零计数；总 RNA 1,551,002 | 保留 prepared 原坐标，单位 unknown；先按 x 中位数固定左半 173 spots | ERBB2/EPCAM/KRT8/PTPRC 实测，MS4A1/CD79A 未测；ROI 与其余 spots 比较，紧凑导出重算一致 |

## 3. 同名条码与同名符号不再丢失身份

两片 SPOTS 的 2,158 个共用原始 barcode 均保留。新的内部 ID 为 `sample:<编码样本>::cell:<编码原始ID>`，同时保存原 `sample_id`、`source_cell_id`；两片新 ID 的交集为 0。错误样本的同名 barcode 不会被接受为本片对象。当前仍是一项目一切片，明确身份不等于已经支持多样本推断。

每片原 `gene_ids` 的 32,285 项唯一 ID 与原符号映射逐项保持一致，其中 38 个发生重复的符号产生 40 条额外重复行；这些符号不改名、不求和。实际 `Ptp4a1` 对应 `ENSMUSG00000026064` 和 `ENSMUSG00000117310`，自动符号查询返回 ambiguous；研究者选择 `feature_id:<ID>` 后才获取各自计数。零表达特征仍在完整轴上，不能把它们删去来消除歧义。`get_feature_catalog` 分页显示原符号与候选 ID；原生 ID 和符号命名空间交叉同名也会提示歧义。

本轮为完整 SPOTS RNA 显式声明 40,000 features / 10,000,000 非零计数的导入预算，没有缩小表达面板。原先重复保存源、基线、目标矩阵会超过离线包预算，因此新增 `compact:true`：一份源快照加不可变修订即可重建。两片源快照分别为 221,608,338 和 237,268,121 字节，均低于每文件 256 MiB，导出前还检查全包 512 MiB。初次无结果导出的核验仅为完整性通过；只有含分析结果的后续导出才能报告重算一致。

接口在真实数据中暴露了返回体过大问题：现在 `open_project` 不附整条 32k 特征映射，通过目录分页；`inspect_selection` 的对象预览只附请求基因，汇总仍覆盖完整选区。坐标点仍有有界的完整视图载荷，不能据此宣称模型上下文成本或研究者效率已验证。

实际浏览器还发现新特征目录与旧项目之间的兼容问题：旧 Xenium 来源没有单独的 feature 映射时，明确的 `feature_id:` 查询曾被错当未测量。现支持旧来源的显式 ID/符号前缀，旧裸基因查询和源散列保持原样；真实 kidney 页面再次检查后，默认五个特征正确显示已测量。对应回归同时覆盖 marker、筛选、区域比较和导出重算。

本机记录：`projects/v04-real-data/spots-axis-identity-verification.json`、两片 `*-receipt.json`、`*-region-review.json`。导入与复核脚本见 `scripts/import_spots_v04.py`、`scripts/verify_spots_axes_v04.py`。契约见 [FORMATS.md](FORMATS.md)。

## 4. 可编辑假设表、完整排序和另一种估计方式

增加共享计划账本：草稿可编辑，修订追加版本；并发旧版本提交拒绝；冻结时绑定源、注释版本、精确选区、全部变量条件和参数。冻结后只能读或运行；再次编辑产生新草稿。计算不修改注释 head，不填写研究者姓名或科学批准。

一个版本包含最多 8 个变体 × 6 个半径 × 2 个图范围。可使用精确 ID 或显式 AND 条件；缺失、null、不可比较类型保持 unknown，假设中有未知成员时保留其 ID 和原因。执行每个组合，局部失败保留 failed 及原因，不把整张表缩成成功子集。所有行进入差异排序，最大绝对效应变化在前，未知/失败仍可见。后看结果再修订的版本不会冒充先前的冻结方案。

每个组合同时计算按边加权与按来源对象等权的观测比例、背景比例及超背景量。前者让每条邻接边投一票，后者让每个有邻居的来源对象投一票；无邻居对象的数量另记，不强行置零。两者是不同的描述性问题，不是谁证明谁正确。独立背景集合及逐来源去自身规则都保存，背景和图范围不再混为一个选项。

真实淋巴结复测沿用历史工作标记程序，不当作已确认的 B/T 身份。新项目有 7,725 个对象、固定 ROI 3,383 个对象。三个原注释假设加一个未测 CD3D 条件，半径 15/35/75 µm、两个图范围，共 **24 格：18 computed、6 unknown**，完整保留。冻结版本为 3（草稿 1→修订 2→冻结 3），各次上下文游标更新，注释版本未改。

独立实现直接遍历坐标距离，核对全部 18 格前后两种方法；原 v0.3 按边结果也一致。紧凑包从不可变源和冻结计划重算匹配。最大等权效应变化约 **0.038458**，但 18 格的预设阈值判断均未翻转。一个具体例子：15 µm、保留 ROI 外邻居，将非单核对象作为不确定工作标签后，来源对象数 **401→364**、边分母 **6,330→5,734**，按边超背景量 **−0.045103→−0.035803**；“稳定”显然不代表数值和分母不变。

等权减按边的超背景差在已计算前后状态间为 **−0.005357 至 −0.000098**。CD3D 负控在每个格保留 7,725 个未知条件成员，不能被当作“没找到细胞”或生物学阴性。这轮真实数据没有 failed 格；失败继续执行的行为使用明确注入的失败回归单独检验，不编造真实运行失败。

独立审读还发现 QC 类型比较漏洞：字符串 `"0"` 与数值 `0` 原本可能被 `ne` 条件选中。修正后类型不兼容为未知，布尔值不当作数值，`in` 也采用三值逻辑；不让元数据解析问题变成细胞排除依据。

本机记录：`projects/v04-real-data/lymph-node-study/acceptance-receipt.json`、`independent-numeric-receipt.json`、`REVIEW.md`、冻结计划及完整结果。复现脚本 `scripts/run_v04_hypothesis_review.py`；完整计划格式见 [HYPOTHESES.md](HYPOTHESES.md)。

审读发现并修复了另一个复算一致性缺口：即使整个包重新计算散列，外层结果、导出 ROI 与内嵌冻结计划也必须绑定同一版本和选区。只检查文件散列不足以发现这种对象矛盾。新增反例在开启或关闭数值重算时均拒绝错绑；保留 `projects/v04-audit/replay-selection-binding/` 的问题与修复复验。首次真实计划验收导出的是完整包；修复后对同一不可变运行另做紧凑导出与重算，收据在 `projects/v04-audit/real-compact-predicate-recheck.json`，没有改写原结果。

## 验收范围

这些证据支持本机功能、身份保留、内容校验和所声明的描述性计算。它们不证明分割或注释准确性，不证明原论文的一般结论稳定，也不证明科研人员效率提升。主淋巴结的同源形态证据、HER2ST/SPOTS 的物理标定、整张组织、多患者分析、真实 ChatGPT/Claude 模型对话和独立研究者对照仍需各自的实际证据。没有外部发布或隧道部署。

回归、原生 napari、浏览器和独立安装包的最终检查见 [VALIDATION.md](VALIDATION.md)。
