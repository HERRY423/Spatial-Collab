# Spatial-Collab 独立研究者试用包

当前状态：准备就绪，尚未招募，实际参与者 0 人。这里没有模拟填写的时间、评分或效率结论。

## 组织者准备

1. 在隔离环境安装仓库的固定依赖和开发包，运行 `scripts/reproduce_v06.py --workspace projects/v06-public --download`。完整方法说明见 `docs/V06_IMPLEMENTATION.md`。
2. 使用公开 SPOTS 与空间 CITE-seq 项目。每位参与者、每种工作流使用独立项目副本，不共用已修改的数据库。保留数据 SHA256、方法版本、模型版本及机器配置。
3. 请未参与开发的科学研究者先为 T1/T2/T3 冻结不同 ROI 的精确对象 ID、任务说明与评分依据，保存到 `frozen_tasks.json`。在此步骤完成前不能开始正式计时。目前没有可信的细胞类型金标准，不能按联合簇与人工标签一致就评分为正确。
4. 对照三种工作流：常规 notebook+查看器、通用 Agent+工具、Agent+Spatial-Collab。全部使用相同输入、整合方法和可用证据；训练练习与正式任务分开。依据 `assignment.csv` 顺序安排，只有实际到场者才填写 enrolled。
5. 统一规定计时口径：主动操作、等待、总耗时各自记录；记录步骤遗漏、返工、计算时间、峰值内存及审阅包。相同数据和方法不代表相同交互成本，不能预先填写节省比例。

## 发给试用者的任务卡

**T1：检查分歧区域。** 对照 RNA-only、protein-only、联合分区。检查指定 ROI 中分歧较大的位置，引用实测 RNA 与 ADT，区分未测量和零值，给出“保留 / 暂不判断 / 建议排除”的理由。分歧本身不是错误或新生物学发现。提交精确对象 ID、版本、使用证据及审阅包。

**T2：比较修改的影响。** 在另一个预定义 ROI 的工作副本中，提出有依据的纳入假设。明确批准的修改才建立正式版本。比较固定模型筛选与重新拟合，解释拟合群体、输出群体和统计分母的变化。提交两种结果，不能只保留支持原判断的一种。

**T3：恢复与复算。** 接手第三个区域的一次中断审阅。恢复版本与选区，识别组织者事先提供的旧版本结果或异样本 ID，说明为什么不能混用。导出后离线验证，提交具体失败或成功记录。

允许回答“不确定”，允许保留失败。任何工作流都不得编造测量、隐式改注释或把簇编号当作细胞身份。

## 记录与评分

使用 `observations.csv`，一行代表一位真实参与者的一次工作流任务；是/否写 1/0，未知留空并解释。评分者记录匿名代码，并声明与开发及该次操作的关系。`reviewer_independence=independent` 是待核实声明，工具不能替代身份核实。

七项评分标准见 `protocol.json`：身份/版本一致、测量状态区分、引用原始证据、固定与重拟合区分、分母、复算、无无依据生物学结论。静默对象错配、版本混用、伪造测量、未批准注释变化均属关键失败。

运行 `python scripts/summarize_user_pilot.py output/v06/user-pilot/observations.csv` 汇总。空表只会返回“无观察数据”。效率比较须同时呈现正确率、关键错误、缺失和学习顺序效应；六位研究者的预实验不能证明普遍收益。

真实 ChatGPT / Claude Code 对话仍需分别由可访问宿主的试用者执行并保存记录。本地 MCP 协议通过不等于两个宿主均已验收。
