# v0.7.0a1 算法落地验收

本次交付实现并实际执行了截图中的六类任务，共 11 个方法入口。状态为本地研究 Alpha；没有独立研究者试用结果，也未证明生物学结论或效率提升。完整机器记录见 `output/v07/public-validation.json`、`executions.jsonl` 和 `results/`；失败尝试保留。

## 公开数据及方法运行

空间数据为原有公开 SPOTS spleen-1（2,568 spots、32,285 RNA 特征、21 蛋白）。本次算法验收采用预先按几何位置定义的 300 spots ROI。参考是官方 scvi-tools 提供的 [sln_111.h5ad](https://exampledata.scverse.org/scvi-tools/sln_111.h5ad)，原文件 SHA256 为 `2098ca88739a9d2d789cb092481c326d7bcbfa73ca815ce3e80b7668cffbe452`。按生产者 Spleen 标签、细胞类型及明确过滤规则保留 3,105 细胞、27 类型、13,553 基因；生产者 `var.gene_ids` 提供与空间数据一致的稳定基因 ID。参考是独立测量的单细胞数据，不是同 spot 配对多组学数据，也不是独立试用验证。

| 方法 | 实际运行输出 | 证据边界 |
|---|---|---|
| MOFA+ | 300 × 4 因子，256 RNA + 21 蛋白，100 轮 | 非空间因子模型 |
| MEFISTO | 300 × 4 因子，128 RNA + 21 蛋白，60 轮 | 实际使用二维坐标与 sparse GP |
| NNLS | 300 × 27 RNA 贡献比例；行和误差 ≤ 2.23e-16 | 不是细胞比例；签名条件数约 417，须评估共线性 |
| Cell2location | 300 × 27 丰度及 5%/95% 后验区间，200 轮 | 运行检查；假设每 spot 8 细胞，未证明收敛，参考均值签名未传播不确定性 |
| Harmony | 600 × 8 校正前后表示 | 同一数据的派生副本控制；不能证明真实批次消除或生物学保持 |
| PASTE | 已知刚体变换控制的坐标 RMSE 0、传输边际误差 0 | 不是独立切片配准准确率；要求完整重叠 |
| SpaGCN | 300 × 8 GCN 表示及 6 个空间簇 | 坐标 + 表达模式，未使用组织图像 |
| 稀疏空间谱聚类 | 300 × 8 表示及 6 个空间簇 | 明示基线，簇不自动成为细胞注释 |
| Moran SVG | 32,285 基因；12,426 检验、19,859 低检出；99 次置换 | BH FDR < 0.05 为 **0**；不报告发现显著 SVG |
| 空间 LR | 3,989 对；3,937 检验、52 不可检验；199 次置换 | BH FDR < 0.05 为 **0**；空间共表达不是信号传递 |
| PROGENy / ULM | 300 × 14 通路；每通路覆盖 89–100 靶标 | 模型推断；小鼠网络由官方同源映射，保留网络及来源 |

19 次任务尝试包含 5 次失败：稳定 ID 命名空间不一致、MOFA/MEFISTO pandas 诊断序列化、Cell2location/scvi 设备参数、PASTE/POT 回调签名。逐项修正后 11 个方法均成功，原始失败仍在任务历史和机器报告中。兼容桥有真实优化器检查与异常恢复检查。

## 规模、正确性与交付检查

- 完整回归：**476 passed、4 skipped**，89.67 秒；跳过项由可选运行环境决定，不计为通过。

- 数值测试包括已知混合物 NNLS 恢复、Moran 直接公式、置换重复性、FDR、错误轴/物种/缺失亚基、混杂设计拒绝、任务失败/取消/缓存和离线 NNLS 复算。
- `pip check` 通过；科学环境独立保存，完整依赖见 `requirements/scientific-py313-win64.lock.txt`。每份结果记录实际环境与实现哈希，历史结果不冒充最终源码重新运行。
