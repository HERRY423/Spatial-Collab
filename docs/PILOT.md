# 下一轮真实任务验证

这一版本证明的目标是状态与计算闭环可以运行。尚未建立生物学有效性、独立研究者体验、节省时间、真实 ChatGPT/Claude 会话接入或公开分发证据。

## 先补三项使用验收

1. 一份具有使用授权的真实 Xenium/AnnData 单切片及已有标签，保留原始文件散列。研究者指定可疑细胞与一个邻域问题；独立脚本核对导入细胞/基因/计数/坐标，不用模型文本作为标准答案。
2. 真实 Claude Code 会话和 ChatGPT 测试连接分别完成同一选择→预览→确认→比较→恢复任务，记录宿主版本、工具调用、选择 ID、revision 和实际可见视图。协议测试不能代替这一步。
3. 由未参与开发的研究者在无人陪同情况下完成一次任务，记录理解错误与返工；确认选区错配、过期结果、单位错误、未测量基因和群体消失能够被识别。

## 与现有工具比较的最小任务

同一份数据与预先固定的问题，对照常规分析、已有 Agent+分析/查看器组合、本插件。固定可固定的模型与计算参数。记录研究者主动操作时间、等待时间、手工转移对象次数、错配/重做次数、结果正确性和再次使用意愿。数据和观察者尽量独立于开发示例。

“主动操作时间减少 30%”只能作为预设目标，不能在完成对照前写成收益。工程测试通过不自动开启产品可用性、科学有效性或推广主张。

## 后续实现顺序

- 接入真实图像/细胞边界与按视口读取，优先评估 Vitessce + SpatialData，检验坐标变换及旧视图失效。
- 在明确科学问题下增加空间结构保持的置换/扰动分析，报告参数网格而非挑选最有利一次。
- 根据试用规模拆分大型矩阵与状态覆盖层，增加任务队列、取消/恢复、成本估计。
- 最后考虑多切片/患者层设计、外部方法适配、可信远程身份授权和公开目录分发。

此排序是本次实现后的建议，不是已执行试用或已验证差异化。
