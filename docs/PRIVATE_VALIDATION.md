## 六个缺口的当前边界

| 缺口 | 工程补齐 | 尚缺的真实环境证据 |
|---|---|---|
| 安装启动 | 独立环境安装器、显式空白/已有项目、确定的启动器和诊断；不改变系统执行策略 | 安装插件后仍需首次运行安装器；不宣称任意新机器一键即用 |
| ChatGPT 连接 | 官方隧道配置与诊断入口，适配 MCP 工具和 UI 资源 | **账号没有开发模式/隧道权限，BLOCKED_ACCOUNT_PERMISSIONS** |
| 内嵌界面 | 协议协商、来源隔离、状态同步、项目切换与关闭清理，模拟宿主测试 | ChatGPT 真实 iframe、宿主权限和重连验收 |
| 文件往返 | 用户选择文件上传、新项目导入、校验后 ZIP 保存 | ChatGPT 文件选择/下载沙箱需实际验证；聊天附件不会自动导入 |
| 公共服务 | 独立 OAuth 资源服务器、项目 ACL、读写 scope、审计及有界请求 | 实际 IdP、OAuth/PKCE 联调、域名、TLS、部署与运维；没有公共服务上线 |
| 发行一致性 | 新版本、源码清单、wheel/ZIP/安装目录逐字节核对脚本与真实 MCP 启动验收 | 不覆盖旧 0.7 包的历史状态，也不等于公开发布或市场审核 |
